---
title: Public SPA
description: Browser-side PKCE authorization code flow with a separate protected API.
---

A public SPA holds no `client_secret` and uses authorization code with PKCE `S256`. The browser bundle
contains only `VITE_*` public values; Reader credentials stay in the API process.

## Public values (injected at build time)

```dotenv
VITE_ISSUER=https://id.example.com
VITE_CLIENT_ID=your-spa-client
VITE_REDIRECT_URI=https://spa.example.com/callback
VITE_POST_LOGOUT_REDIRECT_URI=https://spa.example.com/
VITE_SCOPE=openid profile email
VITE_API_BASE_URL=https://api.example.com
```

## API process values

```dotenv
API_AUDIENCE=urn:app:production
SPA_CLIENT_ID=your-spa-client
READER_CLIENT_ID=your-reader
READER_CLIENT_SECRET=issued-reader-secret
ALLOWED_ORIGIN=https://spa.example.com
ALLOW_INSECURE_LOOPBACK=false
PORT=3001
```

## Run the example

```bash
pnpm install
pnpm --filter @yufu/oidc-spa build
pnpm --filter @yufu/oidc-spa start:api
pnpm --filter @yufu/oidc-spa dev
```

## Flow

1. The SPA uses `oidc-client-ts` with code + PKCE, isolates tabs with `sessionStorage`, and does not
   use iframe silent renewal.
2. The callback verifies state and nonce, then stores the user. Refreshes use the refresh token with
   single-flight per tab to avoid concurrent refreshes.
3. `POST {API}/api/operation` sends `Authorization: Bearer <access_token>`.
4. The API verifies RS256, issuer, `aud=API_AUDIENCE`, `typ=at+jwt`, and expiry locally, then
   introspects with Reader credentials and confirms `active`, `client_id=SPA_CLIENT_ID`, and a
   matching `sub`.
5. Logout clears the local user, uses the RP-initiated endpoint for central logout, and clears caches
   by `sid` / `sub` when back-channel notifications arrive.

## Notes

- Never ship `client_secret` or Reader credentials in a SPA.
- The callback must be registered for this SPA client, not a web client.
- The access-token `aud` is the application's access audience, not the client id.
- Protected APIs must require `typ=at+jwt`; ID Tokens are not access tokens.
