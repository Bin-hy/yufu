# 网关 OIDC、RBAC/ABAC 与执行授权整改 Spec

日期：2026-11-07

状态：已批准。用户已逐段确认全部内容，并于 2026-11-07 批准完整汇总稿；进入技术设计阶段。

本次工作作为一个完整整改阶段，统一设计、实现和验收。内部按依赖拆分任务，最终验收覆盖身份认证、权限决策和网关执行的完整调用链。

## 背景

项目已有 OIDC 登录、凭据验证、角色权限、用户权限覆写和远程权限决策能力，但各入口的安全规则不一致：

- REST、MCP 和网关本地接口的认证及执行权限存在差异。
- 令牌吊销、用途和受众限制未覆盖完整调用链。
- 权限决策缺少目标设备信息，资源范围限制可能失效。
- 部分接口默认放行，任务及结果缺少调用者归属校验。

此前审查以源码分析为主。本阶段需要通过测试确认问题，并为修复建立回归证据。已有审查记录见 [网关与 OIDC 安全审查报告](../../reviews/gateway-oidc-security-review-2026-11-07.md)。该报告是检查线索，不替代实际验证。

## 目标

1. 统一身份边界：明确用户、机器和设备身份，拒绝无效、用途不符及已吊销的凭据。
2. 统一授权规则：明确角色授权、用户覆写和资源约束的判定顺序；未明确授权的操作默认拒绝。
3. 落实资源隔离：授权同时约束操作、目标网关、设备及任务归属。
4. 消除入口绕过：同一主体执行同一操作，通过 REST、MCP 或网关直达入口均受到一致的业务权限约束。
5. 形成验证闭环：覆盖正常访问、越权、吊销、并发重放和依赖故障，并提供迁移说明及脱敏审计证据。

## 功能需求

### F1 身份与凭据校验

所有受保护入口验证凭据的签发方、目标受众、有效期和用途；明确区分用户、机器、设备身份，禁止互相冒用。健康检查等公开接口必须明确列举。

### F2 令牌生命周期

支持签发、到期、刷新、吊销和轮换。被吊销的凭据在约定生效窗口后，不能读取资源、执行操作或申请新凭据；注销和撤销应用授权时，明确终止哪些会话及令牌。

### F3 防重放与并发安全

同一授权码只能成功兑换一次；同一刷新凭据或待轮换令牌只能产生一个有效替代结果。失败或并发请求不得留下额外有效凭据。

### F4 RBAC 与 ABAC 判定规则

对用户权限采用统一顺序：匹配当前操作和资源的显式拒绝 → 用户显式允许 → 角色允许 → 默认拒绝。

显式允许不能突破凭据用途、资源范围及系统安全约束；超级管理员不能绕过显式拒绝。

### F5 资源级权限

对目标应用、网关、设备、工具操作及任务执行资源范围检查。必要资源信息缺失时拒绝授权；列表只返回可见资源，详情和结果读取校验访问权限。

### F6 多入口授权一致性

REST、MCP、远程代理及网关本地接口执行等价操作时，使用一致的业务授权规则。MCP 连接权限不自动包含工具执行权限；代理权限不自动包含下游管理权限。

### F7 网关执行身份绑定

网关只接受经过认证且获得授权的控制请求；设备注册、心跳、能力修改与注销必须绑定设备身份。设备不得覆盖其他设备记录，也不得借注册信息访问未经批准的服务目标。

### F8 任务与结果隔离

任务绑定调用主体和目标网关、设备；结果只能由对应执行方提交。禁止跨用户读取结果、跨网关冒充结果及使用重复任务标识覆盖他人任务；重复投递不得导致同一控制任务重复执行。

### F9 权限管理边界

角色分配、用户覆写、权限规则修改及机器客户端权限同步均需独立授权。机器客户端只能管理明确允许的应用；新增受保护接口未配置授权规则时默认拒绝。

### F10 权限变更与故障处理

权限撤销、角色调整和资源范围变更须在约定窗口内影响后续访问。缓存不得在不同身份、凭据用途或资源间复用授权结果；无法确认身份、吊销状态或必要权限时，不得下发新的控制指令。

### F11 安全审计与凭据保护

记录凭据生命周期、权限变更、授权拒绝和设备执行操作，能够关联主体、目标资源、结果与原因；日志和审计记录不得包含完整令牌、密码或客户端密钥。

## 非功能需求

### N1 安全默认值

生产配置默认开启认证与授权；缺少关键安全配置时拒绝启动相关能力。开发模式如需放宽限制，必须显式启用并清晰提示。

### N2 变更生效时限

吊销、权限撤销、角色及资源范围调整，在操作成功后 10 秒内影响所有实例的新请求。已下发的设备动作不承诺撤回，但不得继续凭旧授权下发新动作。

### N3 故障时的行为

无法取得必要的认证、吊销或授权结论时，拒绝访问受保护资源和下发控制指令；仍在有效窗口内的缓存结论可以使用。区分“明确无权限”与“安全依赖不可用”，便于客户端处理和运维定位。

### N4 性能与容量

认证和授权涉及的网络调用必须有超时，缓存、等待请求及并发校验必须有容量上限。正常请求的安全校验总耗时上限设为 2 秒，超时后返回可识别的失败；验收记录缓存命中与未命中的延迟。

### N5 多实例一致性

安全规则不依赖请求固定落到某个实例；跨实例访问、吊销和权限变更符合相同规则，不得因实例切换恢复已撤销权限。

### N6 兼容与迁移

保留现有合法业务流程；会使旧客户端、令牌或配置失效的变更，必须提供影响清单和迁移步骤。禁止为了兼容而静默跳过安全检查。

### N7 可观测性

认证失败、授权拒绝、吊销检查失败和设备执行均可关联追踪；客户端错误不泄露凭据、内部异常堆栈或无权访问的资源信息。

### N8 验证与回归

安全验收同时覆盖正常、越权、并发、缓存过期、依赖故障和多实例场景；测试使用隔离环境与模拟设备，不向真实设备发送控制指令。所有结论附实际执行证据。

## 不做的事

1. 不替换现有身份平台和技术栈。保留现有 OIDC、角色权限及资源权限体系，在其基础上修复并统一规则；不引入新的外部身份平台。
2. 不建设通用策略编程平台。本轮 ABAC 聚焦用户覆写、应用隔离、网关与设备范围、任务归属及凭据用途；不增加任意脚本策略或复杂策略编辑器。
3. 不改造 VPN 和底层传输协议。不重构 EasyTier、Net4MQTT 或 MQTT 协议实现。相关管理接口的认证授权，以及控制请求和结果的身份绑定仍在本轮范围内。逐设备 VPN 入网、共享网络密钥轮换及网络层节点驱逐留待后续。
4. 不承诺撤回已执行的设备动作。吊销和权限变更约束后续访问与新指令下发；不实现物理动作回滚、紧急停机或已下发任务的通用取消机制。
5. 不全面重做管理前端。只调整本轮安全变更所必需的登录、令牌、权限配置和错误提示，不扩展为界面重设计。
6. 不处理无关业务重构。普通设备调度、音视频、地图等功能仅做必要兼容修改。会破坏身份隔离、授权结果或控制任务防重放的实现错误，仍须修复。
7. 不进行生产攻击测试或自动部署。使用隔离环境验证。部署迁移说明属于交付内容，生产发布、现存凭据批量轮换和真实设备验证需另行安排。

## 验收标准

| 编号 | 对应需求 | 可观察的验收结果 |
|---|---|---|
| AC1 | F1 | 无凭据、错误签发方、错误受众、过期或用途不符的凭据均被拒绝；用户、机器与设备凭据不能越过各自身份边界。 |
| AC2 | F2 | 吊销或轮换成功后，旧凭据在 10 秒内无法通过任何受保护入口读取资源、执行操作或申请新凭据；注销及撤销应用授权符合已声明的失效范围。 |
| AC3 | F3 | 并发兑换同一授权码只有一次成功；并发使用同一刷新或轮换凭据，只产生一个有效替代结果。失败请求不留下额外有效凭据。 |
| AC4 | F4 | 分别验证显式拒绝、用户允许、角色允许和无授权场景；结果符合已确认的优先级，超级管理员也不能绕过匹配的显式拒绝。 |
| AC5 | F5 | 仅获网关 A、设备 A 权限的主体无法访问网关 B、设备 B；列表不包含无权查看的资源，必要资源信息缺失时不能取得授权。 |
| AC6 | F6 | 同一主体执行等价操作，通过 REST、MCP、代理和网关直达入口得到一致的业务授权结果；仅有 MCP 连接权限时不能执行工具。 |
| AC7 | F7 | 未认证设备不能注册或上报；设备 A 不能修改设备 B；未经批准的服务目标不能借注册、重定向或转发被访问。 |
| AC8 | F8 | 用户不能读取他人任务结果；其他网关不能冒充执行方提交结果；重复标识不能覆盖他人任务，重复投递不能重复触发同一控制任务。 |
| AC9 | F9 | 无管理权限的主体不能修改角色、覆写权限或同步权限目录；机器客户端不能写入未获授权的应用；新增受保护接口未配置规则时拒绝访问。 |
| AC10 | F10 | 权限变更在所有实例上 10 秒内生效；缓存不会跨身份、凭据用途或资源错误复用；依赖故障且没有有效缓存结论时，不读取受保护资源、不下发新指令。 |
| AC11 | F11 | 可追溯凭据变更、权限修改、拒绝访问及设备执行的主体、资源、结果与原因；日志中不出现完整令牌、密码和客户端密钥。 |
| AC12 | N1–N8 | 验证安全配置缺失、校验超时、容量超限、多实例切换及旧客户端迁移场景；安全校验超过 2 秒时返回可识别的失败；验收记录实际命令、结果及延迟证据。 |

### 交付验收要求

所有条目必须有自动化测试或明确的操作验证证据。测试因依赖或环境阻塞时，标记为“未验证”，不能视为通过；端到端验证使用模拟设备。
