# 站点品牌与认证页面配置 Checklist

> 依据已批准的 spec.md、plan.md 和 task.md。用户已批准本清单，进入实现和验收。条目仅在对应验证实际通过后勾选。只有获得实际证据才能勾选，验证命令、结果和环境写入 verification.md；缺少环境、未执行或失败的条目保持未勾选。

## 验证约定

- Rust 聚焦集成：`cargo test --test mod site_branding -- --test-threads=1`，使用隔离 PostgreSQL，禁止连接业务数据库。
- Rust 领域/图片单测：`cargo test -p yufu site_branding --lib`。
- Vue 聚焦单测：`pnpm --filter @yufu/web test -- tests/unit/site-branding.test.ts tests/unit/site-settings.test.ts`。
- Chromium 聚焦 E2E：`COBOT_SSO_PW_ARGS='--project=chromium -g site-branding' pnpm --filter @yufu/web test:e2e`。
- 完整浏览器回归：`pnpm --filter @yufu/web test:e2e`；Chromium、Firefox、WebKit 分别记录结果。旧 macOS 使用现有外部 WebKit 运行方式，不能用另一引擎通过替代 WebKit 验证。
- 所有数据库、服务重启、故障注入、迁移和备份恢复验证均针对可销毁的隔离实例；截图和追踪中不保留密码、Cookie、令牌或真实个人信息。

- [x] C03：未登录或已过期/撤销会话访问管理接口返回 401；篡改前端标识不能获得权限。（验证：Rust 聚焦集成，使用无凭据、旧会话及伪造请求，确认配置和素材不变。）
- [x] C04：无登录用户可以读取公开展示配置和已发布图片，响应不含上传人、修改人、管理预览地址、原始覆盖状态或管理限制。（验证：公开接口契约测试，断言返回字段。）
- [ ] C05：超级管理员被显式拒绝某个操作后，该操作被拒绝；上传解码期间被撤权，最终不能写入素材。（验证：授权变更及延迟解码集成测试，查询素材数量和配置版本保持不变。）
- [x] C06：缺少/错误 CSRF 或不可信来源的写请求返回 403，不能修改配置、素材或产生成功审计。（验证：Rust 聚焦集成逐个覆盖保存、恢复及上传。）

- [x] C14：认证页面和登录后工作台均展示已填版权文字、备案号/链接及自定义链接；全部空项无占位或多余分隔符。（验证：Vue 组件测试 + E2E 逐布局观察。）
- [x] C15：文字中的 HTML 和脚本片段仅作为文本显示，不生成标签或执行；链接只接受完整 HTTP/HTTPS 地址，拒绝 javascript、data、相对地址、无主机或含凭据地址。（验证：领域校验 + Vue DOM 断言，输入后观察页面和接口结果。）
- [x] C16：网站名去空白后不能为空，所有文字上限、链接最多 10 项及链接名称/地址上限均按约定验证；限制内接受，超一字符/一项拒绝，错误保留原输入与原配置。（验证：领域边界测试 + 设置页错误显示测试。）

## 图片上传与可见性

- [x] C17：静态 PNG、JPEG、WebP 可用于 Logo/封面/图标，ICO 仅可用于浏览器图标；支持上传、预览、更换和移除。（验证：图片单测 + Rust HTTP 测试 + E2E 实际上传。）
- [ ] C18：Logo/favicon 的 2 MiB、封面的 10 MiB 边界可接受，超一字节返回 413；不依赖 Content-Length，分块超限同样拒绝。（验证：边界与无/伪造长度 HTTP 测试，确认失败未落库。）
- [x] C19：宽和高分别为 8192 像素时符合尺寸规则，任一方向达到 8193 即拒绝；损坏、截断和伪造内容被拒绝，ICO 内嵌图像同样校验。（验证：生成边界素材的图片解码单测，分别断言宽/高边界及坏容器结果。）
- [ ] C20：SVG、GIF、APNG、动态 WebP 和伪造 MIME/扩展名不能绕过验证，失败提示原因，原图和已发布配置不变。（验证：图片素材矩阵 + HTTP 错误测试 + Vue 上传失败测试。）
- [ ] C21：图片解码受单并发限制，排队超时/失败后许可释放，后续合规上传仍能成功；未授权大请求不能进入解码。（验证：受控解码任务单测及 HTTP 权限测试，观察解码调用与后续请求。）
- [x] C22：上传成功但未保存时仅管理预览可读；公开请求随机/已知未发布 ID 与不存在 ID 均为 404；保存引用后公开图片可读。（验证：两种身份请求相同素材地址，比较保存前后状态。）
- [x] C23：图片公开响应提供实际 MIME、nosniff、ETag 和重验证缓存策略；移除引用后携带旧 ETag 请求返回 404，不能得到 304。（验证：HTTP 响应头及条件请求集成测试。）
- [ ] C24：管理配置和管理图片均为 no-store；换图、关闭设置或登出后释放预览 Blob 地址，迟到请求不会在新会话显示旧素材。（验证：响应头集成测试 + Vue 对象地址及会话切换测试。）

## 草稿、保存、恢复默认与审计

- [x] C25：草稿改变立即更新普通/OIDC 预览，但不改变工作台已发布品牌或另一浏览器看到的页面；预览不会调用登录/授权接口。（验证：Vue 请求监控 + 两个浏览器上下文 E2E。）
- [ ] C26：编辑后切换页面、关闭工作区页签或离开浏览器页面会出现适用的未保存提示；取消关闭保留草稿，保存成功后不再提示。（验证：现有工作区机制的组件测试和浏览器操作。）
- [x] C27：一次保存成功后文案、图片引用、版本和成功审计共同更新；配置更新/引用替换/审计写入任一失败时均整体回滚。（验证：隔离事务故障注入，比较文档、revision、引用、素材时间及成功审计数量。）
- [x] C28：两个会话基于同一版本编辑，仅先提交者成功；后提交者收到 409，界面保留草稿并提示重新加载，不自动合并或覆盖。（验证：并发 HTTP 测试 + Vue 冲突测试。）
- [ ] C29：保存中的会话/权限失效后不继续写入；提交结果不确定时不提示成功、不自动重放，可重新读取确认结果。（验证：服务错误路径 + Vue 不确定结果测试。）
- [x] C30：恢复默认先确认，取消不请求且配置不变；确认成功恢复品牌/页脚/外观、清除 OIDC 覆盖、递增版本，旧草稿无法覆盖恢复结果。（验证：Rust 恢复/版本集成测试 + Vue 确认/取消测试 + E2E。）
- [x] C31：首次部署使用默认外观；默认 Logo/图标可用，前后端默认值一致，管理读取失败不会出现可以误保存的默认草稿。（验证：新库集成测试 + 默认配置/Vue 加载失败测试。）
- [ ] C32：身份审计可查看和筛选保存/恢复事件，包含操作者、时间和准确的变更字段，导出也保留这些信息；失败操作无成功记录，摘要不包含图片内容或文案/链接全文。（验证：审计 HTTP 测试 + 列表/展开/导出浏览器操作。）

## 生效、清理与持久化集成

- [x] C33：保存后其他用户下次打开或刷新页面看到更新，无需重新登录、构建或重启；当前设置页面同步新版本，已打开的其他页面不要求实时推送。（验证：两个浏览器上下文 E2E，保留有效会话。）
- [ ] C34：公开配置请求超时、失败或结构错误时使用内置默认外观，不阻塞挂载、不触发登出，普通登录和 OIDC 授权仍可继续。（验证：网络故障 E2E + Vue 非阻塞加载测试。）
- [ ] C35：图片失去最后引用不足 24 小时不被清理，超过期限后被删除；仍有任意引用的图片保留，单批最多 100 张。（验证：隔离数据库和可控时钟测试，比较删除数量与保留内容。）
- [ ] C36：清理与保存同时执行不会删除保存已引用的图片；清理失败后可重试，身份会话和原有清理策略不受影响。（验证：并发事务与失败恢复集成测试，原认证回归通过。）
- [ ] C37：保存后重启隔离服务，配置、图片和版本保持；再次执行升级迁移不重置已保存内容，也不恢复被修改的权限。（验证：重启与迁移集成测试，比较前后配置及图片摘要。）
- [x] C38：按运维文档对隔离数据库备份并恢复至另一个隔离实例，品牌配置、图片及引用均可用；容器持久化说明不要求额外图片文件卷。（验证：实际备份恢复演练，记录命令及恢复前后配置/图片摘要。）
