# 站点品牌与认证页面配置 Spec

## 背景

当前身份平台的网站名称、品牌图标和认证页面文案直接写在界面中，部署者调整这些内容需要修改代码并重新构建。普通登录与 OIDC 登录、授权页面使用共用的认证布局，适合通过统一配置维护品牌展示。

本项目面向单企业自托管场景。本次设置属于整个部署实例，覆盖身份平台的登录页、账户中心、开发者控制台和企业管理界面；独立的项目宣传官网不在本次范围内。

## 目标

- 提供超级管理员专属的「站点设置」，部署者可通过界面维护网站品牌、认证页面外观及页脚信息。
- 使用全站统一品牌配置，允许 OIDC 登录与授权页面单独覆盖封面、欢迎标题和说明文案。
- 配置和上传图片持久保存，保存后下次打开或刷新页面生效，无需重新构建、重启或重新登录。
- 未配置、配置读取失败或图片加载失败时使用内置默认内容，保证登录和授权流程可继续。

## 功能需求

- **F1 专属设置入口**：仅超级管理员可查看管理配置、修改站点设置和上传图片。普通企业管理员、开发者、成员和未登录用户均无权操作；服务端同步校验权限，不能仅依赖隐藏入口。
- **F2 全站品牌**：支持配置网站名称、简介、Logo 和浏览器图标，统一用于导航、登录与授权页面、浏览器标题等品牌展示位置。浏览器标题保留当前页面名称。
- **F3 登录页外观**：支持配置封面图片、欢迎标题和说明文案，图片适配桌面与移动端，保证登录表单清晰可用。
- **F4 OIDC 页面覆盖**：OIDC 登录与授权页面默认继承全站配置。封面、欢迎标题和说明文案可分别覆盖；未设置或清除某项覆盖后，该项恢复继承。应用名称、授权范围等认证信息保持由系统生成，不允许通过外观配置修改。
- **F5 页脚**：支持配置版权文字、备案号及链接、自定义链接，适用于认证页面和登录后的工作台；空项不展示。
- **F6 图片管理**：支持直接上传 PNG、JPEG、WebP 图片，浏览器图标另支持 ICO。支持预览、更换和移除，并明确提示格式与大小限制。第一版通过上传管理图片，不支持外链图片。
- **F7 预览与保存**：编辑时可预览全站与 OIDC 外观，点击保存后统一生效。未保存的修改不影响其他用户，离开时提示未保存内容。
- **F8 默认与持久化**：初始使用项目默认外观，恢复默认须经确认，取消不改变配置。已保存内容和图片在服务重启、版本升级后保留。
- **F9 变更记录**：保存及恢复默认操作记录操作者、时间和变更项，便于追溯；失败操作不能被记录为成功。

## 非功能需求

- **N1 权限与公开读取**：设置管理及上传校验登录状态、超级管理员权限和请求来源。未登录用户只能读取页面展示所需的公开配置，不能读取管理配置。
- **N2 内容安全**：文字按纯文本展示，不支持自定义 HTML、脚本或 CSS。页脚链接仅允许 HTTP/HTTPS 地址。图片同时校验实际格式和文件大小，不接受 SVG。
- **N3 上传限制**：Logo、浏览器图标每张不超过 2 MiB，封面每张不超过 10 MiB；图片宽、高均不超过 8192 像素。无效上传明确提示原因，保留原配置。
- **N4 一致性**：一次保存全部成功后才发布，失败时继续使用原配置。多人同时编辑发生冲突时提示重新加载，避免覆盖他人修改。
- **N5 生效与容错**：保存成功后，其他用户下一次打开或刷新页面即可看到新配置，无需重新登录。不向已打开的页面实时推送。配置加载失败或图片无法显示时使用内置默认内容，登录与授权流程仍可继续。
- **N6 显示适配**：兼容现有浅色、深色主题及移动端；图片保持比例，封面允许裁切，Logo 完整展示，长名称和文案不遮挡表单与操作按钮。
- **N7 持久化与部署**：配置和上传图片均支持持久保存，部署文档明确备份、恢复及容器持久化要求。版本升级不覆盖用户已保存的配置。

## 不做的事

- 独立宣传官网的品牌与内容配置。
- 按不同 OIDC 应用分别定制外观。
- 自定义 HTML、CSS、脚本、页面布局及主题配色。
- 外链图片、SVG、动态图片、在线裁剪和素材库管理。
- 修改登录方式、OIDC 协议参数、账户权限及授权提示；本次只配置展示内容。
- 配置历史版本回滚、定时发布和已打开页面的实时更新。

## 验收标准

- **AC1（F1、N1）**：超级管理员可进入设置并保存；普通企业管理员、开发者、成员及未登录用户无法读取管理配置、修改配置或上传图片，直接请求接口同样被拒绝。未登录用户可读取页面展示所需的公开配置。管理写入请求来源校验失败时，操作被拒绝且配置不变。
- **AC2（F2）**：修改网站名称、简介、Logo 和浏览器图标后，刷新相关页面，各品牌展示位置使用新配置，浏览器标题保留当前页面名称。
- **AC3（F3、N6）**：上传封面并修改欢迎文案后，普通登录页正确展示；桌面、移动端及浅深色主题下，表单均可正常使用。Logo 完整展示、封面保持比例并允许裁切，长名称和文案不遮挡操作。
- **AC4（F4）**：未设置 OIDC 覆盖时使用全站配置；单独覆盖某一项只影响该项，清除后恢复继承。OIDC 登录和授权仍能完成，应用名称及授权范围保持准确。
- **AC5（F5、N2）**：认证页面和工作台页脚正确展示已填写的版权、备案信息和链接，空项不占位；危险链接被拒绝，输入的 HTML 按纯文本显示。
- **AC6（F6、N2、N3）**：合规图片可上传、预览、更换和移除；超出大小或尺寸限制、伪造格式及不支持的文件被拒绝并提示原因，原配置保持可用。Logo 与浏览器图标按 2 MiB 限制、封面按 10 MiB 限制，宽高分别按 8192 像素限制验证边界；ICO 仅用于浏览器图标，SVG 和动态图片被拒绝。
- **AC7（F7、N4）**：未保存的修改仅出现在预览中，其他用户看到的配置保持不变；离开时提示未保存内容。保存失败不发布部分修改；发生并发冲突时提示重新加载，不覆盖已保存的新版本。
- **AC8（F8、N7）**：首次使用显示默认外观；恢复默认须确认，取消不改变配置。服务重启及升级后配置和图片保留，并可按部署文档备份恢复，包括容器部署场景。
- **AC9（F9）**：保存及恢复默认后，审计记录能查看操作者、时间和变更项；失败操作不会被记录为成功。
- **AC10（N5）**：保存成功后，其他用户下次打开或刷新页面即可看到更新，无需重新登录；配置读取失败或图片加载失败时回退默认内容，登录与授权仍可继续。
