# yufu 工作台改版需求

状态：需求、视觉方向、技术设计、任务单和验收清单均已获用户批准，2026-11-08；前端实现与工程自动化验证已完成，真实环境及未覆盖项见 [验收报告](acceptance-report.md)。

## 背景与目标

现有用户与授权管理界面存在可复现的分页状态丢失、请求响应乱序、折叠导航不可用、异步确认过早关闭及窄屏正文被挤压等问题。页面视觉和反馈方式也不统一。

本次目标是把平台改为适合连续管理工作的统一工作台：导航与数据状态可预测，用户能保留工作上下文，操作反馈明确，桌面与小屏均可使用。视觉以清晰的信息层级和一致的交互为基础。

## 功能需求

- F1 首页与导航：提供与用户、权限和应用管理相关的概览及常用入口；首页只有一个固定标签。导航按身份、访问控制、应用与授权、审计分组；折叠、小屏及历史跳转都能访问各页面，活动入口始终可辨认。
- F2 标签工作流：保留多标签工作台。切换标签恢复该标签最近的地址、分页、筛选及必要的滚动位置；同一列表的查询变化更新已有标签，详情按对象区分。支持关闭当前、关闭其他、关闭右侧；固定首页不关闭。导航被取消或失败时标签与内容保持原状态。
- F3 工作上下文与会话：列表在切换页面后保留筛选和分页；表单草稿在切换后可继续，关闭前提示未保存修改。刷新恢复已打开标签与完整地址，校验无效地址与权限，敏感字段不落入浏览器持久化。退出、会话失效或更换账号时清理上一会话标签与页面状态。
- F4 查询与分页：可分享的地址能恢复当前页、页大小与有效筛选；后退/前进同步显示状态。筛选变化回到第一页；页码与输入有边界校验。搜索明确覆盖范围；全量搜索需要真实接口支持，当前页搜索必须明确标注。
- F5 异步数据反馈：每个数据区域区分首次加载、刷新、正常空结果、失败和成功；失败提供重试。快速查询时只显示最后一次有效查询结果；旧请求不能提前结束当前 loading。首次进入页面避免重复请求。选项加载失败不阻止其他独立区域展示。
- F6 保存与危险操作：保存、删除、撤销、踢下线等操作显示请求中状态，阻止重复提交。异步确认成功后关闭，失败保留对象、用户输入及重试入口；用户可明确取消未提交操作。确认展示对象与真实影响，部分成功须明确提示并同步真实状态。
- F7 表单与弹层：输入有名称、标签、校验和明确的错误定位。弹窗、抽屉、菜单使用一致的关闭与焦点行为；支持键盘和 Esc，关闭后回到触发入口。表单通过任何导航入口离开均检查未保存修改，确认留在页面后数据保持完整。
- F8 用户与角色：统一列表页头、查询工具栏、表格、分页与行操作；创建与编辑使用一致的表单规则。角色修改、权限覆写、删除及踢下线保留现有业务能力，反馈与查询状态遵循 F4–F7。
- F9 权限与分配：明确区分 API 权限与资源权限。分配界面能识别角色、已有权限、新增与移除项；支持搜索和已选计数。可选角色与权限不因静默数量上限而遗漏；大数据集按真实接口能力分页或继续加载；失败、部分完成和取消行为明确。
- F10 应用与审计：应用注册、已授权应用、操作记录和个人中心统一迁移。应用的密钥、授权、作用域及撤销后果有清晰层级；记录按用户或其他已有筛选加载，并独立加载选项。敏感内容只在业务确需时显示，操作不依赖仅图标或颜色传达。
- F11 入口体验：登录、注册、OIDC 登录与授权、错误页采用同一视觉语言。普通登录成功后恢复合理的原目标；OIDC 流程保留授权参数与协议跳转，加载失败有明确反馈。
- F12 统一工作台：桌面提供分组侧栏、顶部工具栏、面包屑、单行标签与内容区；小屏提供导航抽屉。标准化字体、间距、按钮、表格、状态标签和提示；浅色、暗色及系统主题一致，尊重减少动画设置。

## 非功能需求

- N1 兼容性：覆盖桌面 Chrome、Edge、Firefox、Safari 当前稳定版本，以及 iOS Safari / Android Chrome 的基本操作。正式验收记录实际测试的版本，不用一次 Chrome 测试代替全部兼容性。
- N2 布局：至少验证 1440×960、1280×800、768×1024、390×844、360×800；正文不被侧栏占据，标签不纵向换行，宽表格在局部容器内滚动。键盘焦点不被固定区域覆盖。
- N3 可访问性：采用可读的标签、语义结构和可见焦点；普通文本目标对比度至少 4.5:1；主要流程可用键盘完成；异步结果可被读屏感知；交互命中区域至少 24×24 CSS px，小屏主要操作目标 44×44。
- N4 性能与稳定性：页面加载不串行等待非必要的全量选项；同一查询只发起必要请求；分页和大列表按需求加载；界面可中断动画且导航操作不被出场动画阻塞。性能优化以测量与实际问题为依据。
- N5 工程验证：类型检查与生产构建通过；导航、查询乱序、弹窗失败、会话切换和草稿保护有行为回归；已有有效 lint 规则通过。新增检查覆盖真实失败路径，不用只检查实现细节的测试代替行为验证。
- N6 迁移一致性：改版使用现有业务接口与认证约定；保留现有入口的兼容跳转。公共组件调整须验证其他工作区应用。视觉验收使用真实状态截图或明确标注的模拟数据，首页不伪造统计。

## 边界与取舍

本轮覆盖 yufu 当前业务页面及其前端基础交互。后端认证协议、权限模型、数据库及 cobotsrv / cobotlet / cobotimx 的独立界面重做不属于当前需求。后端缺少全量搜索、聚合统计或事务接口时，前端明确展示能力边界，并在技术设计中记录单独依赖，不能假装已支持。

保留 Vue 与多标签工作台是建议默认方向。具体组件库、缓存实现、请求取消方案及文件拆分在技术设计阶段决定。拖拽标签排序、新统计接口及大规模图表属于后续扩展，本轮不作为验收前提。

## 可观测验收标准

| 标准 | 对应需求 | 验证行为 |
|---|---|---|
| AC1 | F1 | 首次进入只有一个首页标签；展开、折叠、小屏、地址直达和历史跳转均可访问核心页面；当前分组正确显示 |
| AC2 | F2 | 用户列表第 3 页 → 角色 → 用户 tab 后仍为第 3 页；查询变化不重复建标签；关闭当前/其他/右侧结果正确；导航失败不丢标签 |
| AC3 | F3 | 表单草稿切换后保留；刷新恢复允许持久化的标签与地址；敏感表单值未被持久化；退出换账号后没有上一账号 tab 或草稿 |
| AC4 | F4 | 直达地址、分页、筛选、后退/前进保持一致；非法页码按边界处理；搜索范围清晰，筛选变更从第一页开始 |
| AC5 | F5 | 第 2 页慢响应、第 3 页快响应后只显示第 3 页；首访列表无重复拉取；加载、失败、空状态明确区分并可重试 |
| AC6 | F6 | 模拟 1 秒提交：期间按钮 busy 且无法重复提交；模拟失败后弹窗仍在并保留对象；成功后关闭并刷新结果；部分失败有准确提示 |
| AC7 | F7 | 仅键盘完成打开、编辑、确认/取消弹窗；焦点不逃逸且返回触发按钮；字段错误可定位；点击 tab/侧栏、后退、刷新均保护脏表单 |
| AC8 | F8 | 用户、角色列表的分页、创建、修改、权限覆写、删除和踢下线具备一致状态反馈；操作后列表显示真实结果 |
| AC9 | F9 | 超过单次获取上限的数据能够继续获取且无静默遗漏；分配页面显示准确的新增/移除与已选计数；失败可重试且不会误报成功 |
| AC10 | F10 | 应用与授权、审计、个人中心的主要操作完成；记录首屏不等待全部用户页；筛选重置页码；密钥与危险操作展示清晰 |
| AC11 | F11 | 普通登录恢复目标地址；OIDC 登录与同意/拒绝路径保留请求参数并按原协议跳转；失败页可理解并有可用下一步 |
| AC12 | F12 | 指定多视口截图中正文可用，tab 单行可滚动；浅色/暗色/系统主题一致；减少动画设置有效；全模块遵循同一组件规范 |
| AC13 | N1–N6 | 实际浏览器版本、构建结果、行为回归、主题对比与公共组件影响均有记录；真实认证联调通过；未支持的后端能力明确说明 |

## 审阅重点

用户已确认方案 A：保留 Vue 与业务接口，统一导航、状态及交互基础，按用户/角色样板 → 权限/应用/审计 → 入口验收逐步重构。需求批准不代表实现或验收完成；后续阶段分别记录实际状态。
