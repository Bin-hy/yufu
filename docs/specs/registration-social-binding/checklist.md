- [ ] 注册页只展示 enabled/configured 的 OAuth Provider；读取失败时隐藏且不阻断注册。（验证：前端单元测试与手动页面。）

## 注册同步绑定验收

- [ ] **AC1 Provider 展示。** 仅启用 GitHub 时注册页只出现 GitHub；禁用后刷新入口消失且注册仍可提交。（验证：调整 runtime registry 或测试 mock 后观察页面。）
- [ ] **AC2 仅创建账户。** 不选 Provider 提交有效邀请：账户创建成功、中心会话 Cookie 下发、`requires_login=false`；无需再次输入密码即可访问账户中心。（验证：HTTP 测试与 E2E。）
- [ ] **AC3 选择 Provider 注册。** 选择 GitHub 提交：账户创建成功、会话建立、邀请被消费，并自动进入 GitHub 授权地址，无第二次密码输入。（验证：fake GitHub 集成测试。）
- [ ] **AC4 绑定成功。** fake GitHub 回调后存在用户与 GitHub 映射，页面进入身份页或原 OIDC 流程，无失败提示。（验证：`cargo test --test mod external_identity_github`。）
- [ ] **AC5 绑定取消/失败。** 取消或 fake Provider 返回错误：账户仍存在且可访问账户中心，邀请保持已消费，映射不存在；有 `flow_id` 时继续 OIDC，否则身份页显示错误。（验证：fake Provider 错误路径测试。）
- [ ] **AC6 注册原子性。** 让会话或审计写入失败：邀请仍待用、账户不存在、响应失败；故障移除后重试成功。（验证：数据库触发器集成测试。）
- [ ] **AC7 并发接受。** 两个请求同时接受同一邀请：最多一个成功，另一个返回已消费/冲突；数据库只消费一次。（验证：并发 HTTP 测试。）
- [ ] **AC8 OIDC 安全。** 不匹配浏览器或伪造 `flow_id` 被拒绝，无开放重定向；合法流程在成功和失败后都能继续。（验证：外部绑定 flow 测试与跳转断言。）
- [ ] **AC9 已有账户不变。** 已登录账户打开邀请不显示 Provider 区域，接受后按原逻辑继续；账户中心绑定/解绑、密码登录、密码找回无回归。（验证：既有测试与手动页面。）

## 邀请记录验收

- [ ] **AC10 历史可见。** 签发后刷新或重新进入管理页仍显示记录；不选择 Provider 的记录也可见；空数据有状态。（验证：管理页手动刷新与前端测试。）
- [ ] **AC11 状态正确。** 待用/已接受/已撤销/已过期为对应状态；已接受记录即使同时到期或撤销仍显示已接受。（验证：构造四类记录后调用列表。）
- [ ] **AC12 筛选与分页。** 状态、用途、人员类型筛选和搜索返回正确结果；超过一页时游标加载不重复不遗漏，单页不超过 50 条。（验证：`identity_invitations` 分页测试。）
- [ ] **AC13 撤销。** 撤销待用邀请后链接立即不可用，其他并行链接仍可用；非待用记录不能撤销；审计新增事件。（验证：撤销后兑换旧 secret 失败，其他 secret 成功。）
- [ ] **AC14 重新签发。** 对四类记录重新签发：每次新记录/新链接，原记录字段和状态不变，原待用链接仍可用；新链接只展示一次且可完成注册。（验证：接口与数据库断言。）
- [ ] **AC15 重新签发校验。** 目标账户停用或不存在时拒绝且不创建记录；新有效期使用当前配置。（验证：停用目标账户后重签发返回错误，记录数不变。）
- [ ] **AC16 多链接并行。** 同一目标连续重签发两次后存在三条待用记录，三条链接可独立使用或撤销。（验证：列表与三个 secret 的兑换测试。）
- [ ] **AC17 秘密保护。** 列表响应、审计详情、错误信息和日志无 secret/digest/token；旧链接无法从管理接口恢复。（验证：响应文本搜索与代码审查。）
- [ ] **AC18 权限。** 无账户读取权限访问列表被拒绝；无签发权限不能重签发；无撤销权限不能撤销；有权操作成功并记录操作者。（验证：权限矩阵 HTTP 测试。）
- [ ] **AC19 状态时间。** 测试时钟推进到到期时刻，记录立即变为已过期；前端使用服务端状态，不因本地时钟误判。（验证：注入时钟测试与页面观察。）
- [ ] **AC20 审计。** 签发、接受、撤销、重签发、同步绑定成功/失败均产生可检索记录，包含关联标识且不含敏感材料。（验证：查询 `identity_audit_event`。）

## 界面与兼容验收

- [ ] **AC21 可访问性。** Provider 卡片、筛选、撤销和重新签发可键盘完成；状态有文本；提示可被辅助技术读取。（验证：键盘操作与 DOM 属性检查。）
- [ ] **AC22 响应式。** 窄屏下注册页、列表、撤销和重签发可完成，关键状态和按钮不裁切；复制失败可手动选择链接。（验证：窄屏浏览器观察。）
- [ ] **AC23 兼容性。** 旧邀请链接仍可完成原流程；旧客户端忽略新增字段仍工作；下游 OIDC 客户端无需修改。（验证：旧链接 E2E、OIDC 回归测试。）
- [ ] **AC24 失败可恢复。** Provider 目录、列表、撤销、重签发和绑定失败时页面保留上下文并提供重试/返回路径，无空白页或静默失败。（验证：故障注入与手动操作。）

## 非功能与安全

- [ ] **N1/N9/N11 信息最小化。** 列表、审计摘要、日志不包含邀请 secret、摘要、Provider token 或 client secret；列表只展示管理所需账户信息。（验证：响应/日志搜索与代码审查。）
- [ ] **N2/N3 服务端校验。** Provider 展示与绑定、邀请有效性、状态和权限均以服务端为准；伪造 Provider 请求被拒绝。（验证：禁用 Provider 后伪造 bind 请求。）
- [ ] **N4/N5 一致性与并发。** 账户/邀请/会话原子；同一邀请并发接受只成功一次；撤销与接受竞争有确定结果。（验证：故障注入与并发测试。）
- [ ] **N6 失败隔离。** 绑定取消/失败、目录失败、列表失败不会删除账户或回滚邀请状态。（验证：错误路径测试。）
- [ ] **N7/N8 性能与数据量。** 列表服务端分页且单页 ≤50，不会一次加载全部历史；筛选和搜索在服务端执行。（验证：请求参数与 SQL 审查；分页测试。）
- [ ] **N10 审计一致性。** 邀请写操作与审计同事务；外部失败有结构化日志或尽力审计。（验证：触发器失败测试与日志检查。）
- [ ] **N12 兼容性。** 旧邀请链接、已有账户接受、普通登录、绑定/解绑、密码找回、下游 OIDC 均通过回归。（验证：既有测试套件。）
- [ ] **N13 会话一致。** 自动会话与密码登录使用相同的有效期、CSRF、浏览器绑定、停用处理和撤销机制。（验证：检查 Cookie 属性与会话接口；停用账户后绑定失败。）
- [ ] **N14 时间一致。** 状态由服务端时钟计算，`now >= expires_at` 即过期；前端不自行推导状态。（验证：固定时钟测试。）
- [ ] **N17 OIDC 安全。** 只续接服务端存在且浏览器绑定的流程；不能接受客户端任意跳转地址；回调不是开放重定向。（验证：伪造 flow 和恶意参数测试。）
- [ ] **N18 测试覆盖。** 原子性、并发、失败、OIDC 续接、分页筛选、多链接并行均有自动化测试，且不依赖真实第三方。（验证：fake Provider 测试清单。）

## 端到端场景

- [ ] **场景 1：邀请开户并同步绑定。** 管理员签发邀请 → 接收人打开链接 → 选择 GitHub → 创建账户并自动登录 → fake GitHub 授权成功 → 身份页显示已绑定；全程只输入一次 Yufu 密码。（验证：fake Provider E2E 或集成测试。）
- [ ] **场景 2：绑定取消。** 接收人选择 Provider → 创建账户 → 在第三方取消 → 回到身份页或 OIDC；账户仍可访问，绑定未发生，邀请已消费。（验证：fake Provider 取消路径。）
- [ ] **场景 3：邀请记录。** 管理员签发邀请 → 刷新页面 → 列表可见 → 撤销原链接 → 新链接不可用 → 重新签发 → 新链接可用且旧的其他待用链接仍可用。（验证：管理页 E2E/API 测试。）
- [ ] **场景 4：OIDC 续接。** 从客户端发起 OIDC → 无会话进入邀请注册 → 创建账户并绑定 → 回到同意页完成授权 → 客户端收到 code。（验证：OIDC + fake Provider 集成测试。）
- [ ] **场景 5：已有账户。** 已登录用户打开邀请 → 无 Provider 卡片 → 接受邀请 → 按原逻辑继续 OIDC；账户中心绑定/解绑仍正常。（验证：既有账户测试。）
