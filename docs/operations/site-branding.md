# 站点品牌与认证页面配置

超级管理员登录后进入「系统设置 → 站点设置」（`/admin/site-settings`）。普通企业管理员、开发者和成员没有此入口，管理接口也会拒绝访问。

## 配置与发布

1. 在「全站品牌」填写网站名称、简介，上传 Logo 和浏览器图标。
2. 在「普通登录页」上传认证封面并编辑欢迎标题与说明。
3. 在「OIDC 登录与授权页」按需设置独立封面和文字。每项独立继承：未覆盖的项随全站配置变化；清除图片覆盖、关闭文字自定义后恢复继承。自定义文字留空表示隐藏该项。
4. 在「页脚信息」填写版权、备案号及备案链接，添加自定义链接。空项不展示。
5. 检查右侧普通/OIDC 外观预览，点击「保存设置」。图片上传和草稿预览本身不发布配置。保存后其他用户下次打开或刷新页面生效，不需要重新登录、构建或重启。

网站名称和图标用于全站品牌位置；OIDC 应用名、scope、账户身份和授权说明继续由系统生成。设置作用于整个部署，不支持按各应用分别定制，也不影响独立宣传官网。

保存冲突时，页面保留草稿并提示重新加载。先自行保留需要的输入，再确认重新加载当前配置。网络错误或提交结果不确定时先重新读取配置核对，不连续重复提交。管理配置读取失败时不能用默认值覆盖已保存配置。

「恢复默认」需要确认，成功后清除所有覆盖和图片引用，并生成新的配置版本；取消不会修改配置。没有历史版本回滚入口。

## 图片与文字限制

| 内容 | 限制 |
| --- | --- |
| Logo、浏览器图标 | 每张最多 2 MiB |
| 全站/OIDC 封面 | 每张最多 10 MiB |
| 图片宽、高 | 各最多 8192 像素 |
| 图片格式 | 静态 PNG、JPEG、WebP；浏览器图标另支持 ICO |
| 不接受 | SVG、GIF、APNG、动态 WebP、损坏或伪造内容 |
| 网站名/简介 | 80 / 300 个 Unicode 字符；网站名不能全为空白 |
| 欢迎标题/说明 | 120 / 1000 个 Unicode 字符 |
| 版权文字/备案号 | 300 / 100 个 Unicode 字符 |
| 自定义链接 | 最多 10 个；名称 80、地址 2048 个字符 |
| 链接地址 | 完整 HTTP/HTTPS 地址，不能包含用户名或密码 |

文字作为纯文本展示，不支持 HTML、CSS 或脚本。Logo 完整等比展示，封面等比裁切；移动端使用现有紧凑认证布局。没有在线裁剪或外链图片功能。

上传素材只允许超级管理员预览，保存后当前配置引用的图片才公开。无引用素材保留 24 小时，后台每批最多清理 100 张；超过期限的未保存草稿可能需要重新上传。移除已发布图片后，其公开地址不再可用，数据库中的旧内容到期后清理。已经下载到用户设备的副本无法撤回。

## 持久化和容器部署

配置、图片原始内容及引用全部保存在 PostgreSQL 的 `site_settings`、`site_asset`、`site_settings_asset_ref` 表。运行期图片不写入应用二进制，也不需要额外上传目录或文件卷。

容器部署需要持久化 PostgreSQL 数据目录，沿用现有数据库卷方案。不要将有业务数据的数据库卷当作临时容器删除。服务重启、重建应用容器和正常升级不会重置已保存品牌；新迁移追加表和操作注册，不覆盖现有权限或显式拒绝。

公开配置读取失败或图片加载失败时，前端使用内置默认外观；身份服务本身可用时，登录和 OIDC 授权仍可继续。

## 备份与恢复

品牌与身份数据在同一数据库，沿用完整数据库一致性备份，不单独导出三张表，否则可能丢失引用的用户/权限或恢复顺序依赖。连接凭据使用本地受保护的环境或密码文件，不写入日志或命令示例。

以下命令使用 PostgreSQL 连接环境变量 `PGHOST`、`PGPORT`、`PGUSER`、`PGDATABASE` 与受保护的 `.pgpass`，备份文件路径由操作者指定：

```sh
pg_dump --format=custom --no-owner --file=/secure/backups/yufu.dump
```

恢复到独立、空白的目标数据库，设置相应连接环境后执行：

```sh
pg_restore --no-owner --exit-on-error --dbname="$PGDATABASE" /secure/backups/yufu.dump
```

目标数据库应由部署角色拥有，并使用与服务兼容的 PostgreSQL 版本。生产恢复须沿用既有身份服务恢复方案，保留固定 issuer、签名私钥和部署配置；恢复前停止写入，先在隔离环境验证。不要把备份恢复命令直接指向正在使用的业务库。

恢复后启动对应版本服务，检查：

- 超级管理员能读取当前配置及版本；普通用户仍不能访问管理接口。
- 普通登录与 OIDC 页面使用保存的品牌，已引用图片可读取。
- 图片内容摘要、站点名称、覆盖项、页脚及当前版本与备份前一致。
- 执行正常升级迁移后，已有配置、图片及权限保持。

## 容量与审计

数据库备份体积包括所有已引用图片和等待清理的素材。每个配置最多引用四个槽位；频繁上传会增加暂存空间，需监控数据库和备份大小。

图片完整解码在 blocking 任务中执行，单进程同一时刻最多一个解码任务；等待和请求体读取有超时。解码设置 512 MiB 分配预算，这不是进程内存硬上限。8192 × 8192 的 16 位 RGBA 原始像素约占 512 MiB，部署还需预留解码临时缓冲、服务和数据库资源；常规 Logo 和封面应使用符合展示尺寸的小图。

在「企业管理 → 身份审计」中按对象类型 `site_settings` 筛选。动作 `site_settings.saved` 表示保存，`site_settings.reset` 表示恢复默认。记录包含操作者、时间、版本和变更字段，不包含图片内容或整段文字/链接。失败操作不会产生成功记录。
