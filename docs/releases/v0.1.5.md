# yufu v0.1.5 Release Notes

> 对比基线：`v0.1.3`
> 分支：`main`
> 版本：`0.1.5`
> 说明：`v0.1.4` tag 因 `url 2.5.8` 的 RUSTSEC-2026-0592 在发布质量门禁失败，未生成 Release；`v0.1.5` 使用 `url 2.5.9` 修复后发布。

## 重点更新

### 安全修复

- 升级 `url` 到 `2.5.9`，修复 RUSTSEC-2026-0592（嵌套 `blob:` URL 导致 `Url::origin()` 栈溢出）。
- 同步更新 `form_urlencoded` 到 `1.2.3`。

### 第三方身份登录与绑定

- 新增 GitHub、QQ、微信开放平台网站应用扫码登录。
- 支持登录、绑定、解绑，以及账户中心查看已绑定身份。
- 管理端支持 Provider 启用/禁用、Client ID 与 Secret 配置、Secret 轮换、revision 冲突提示和登录统计。
- 外部登录成功后继续原有 OIDC Authorization Code Flow，下游 OIDC Client 不需要修改接入方式。
- 外部身份与 Yufu `sub` 分离；不按邮箱、昵称或 unionid 自动合并账号。
- 未绑定身份默认拒绝登录；可配置 `registration=open` 自动创建无密码外部账号。

### 邀请注册同步绑定

- 新建账户邀请注册页会展示服务端已启用的第三方登录 Provider。
- 接受邀请时，账户创建、邀请消费和中心会话建立在同一事务内完成，不需要二次登录。
- 选择 Provider 后可直接继续第三方授权；绑定成功继续原 OIDC 流程，取消或失败保留账户和会话。
- 新账户接受邀请的 `requires_login` 现在为 `false`；已有账户接受邀请流程保持兼容。

### 邀请记录

- 管理端新增邀请历史列表，展示用途、人员类型、开发者资格、目标账户、创建人、状态、接受人和期限。
- 状态由服务端派生：已接受 > 已撤销 > 已过期 > 待用。
- 支持状态/用途/人员类型筛选、搜索和游标分页（单页不超过 50 条）。
- 待用邀请可撤销；任意历史记录可重新签发。
- 重新签发创建新记录和新链接，旧记录与旧链接保持有效；同一目标允许多条待用链接并行。
- 列表和审计不返回 secret 或摘要；旧链接无法恢复，只能重新签发。

### 界面与文档

- 全局界面文字精简，更多使用布局、图标、状态徽章和 tooltip 承载说明。
- 更新 README 的结构化接入、Docker 演示和安装入口说明。
- 增加语言无关的 SDK contract fixtures、Python SDK 指南和 onboarding skill 文档。
- 新增外部身份设计、spec、运维文档和邀请注册同步绑定验收文档。

## 升级说明

- 数据库迁移为增量式，新增外部身份相关表与索引；邀请记录复用现有 `identity_invitation` 表，启动时自动迁移。
- 既有 OIDC Discovery、Token、UserInfo、会话撤销和密码登录流程保持兼容。
- Provider 默认禁用；升级后需要在 **企业管理 → 第三方登录** 配置 Client ID/Secret 并启用。
- 主密钥 `YUFU_EXTERNAL_SECRET_KEY` 必须为 base64 编码的 32 字节；Secret 使用 AEAD 加密存储，缺失主密钥时 Provider 配置失败关闭。
- 邀请链接格式不变；已有邀请链接继续可用。新建账户接受邀请后会自动登录，不再要求二次输入密码。
- 重新签发不会自动撤销旧邀请；如需停止旧链接，请单独撤销。

## 平台状态与限制

- GitHub：代码、fake Provider 测试和本地真实 OAuth 登录/绑定联调通过；生产环境需配置 GitHub OAuth App 回调。
- QQ：代码与 fake Provider 测试通过；真实联调待 QQ 互联应用/ICP/审核。未审核应用仅开发者或协作者 QQ 可测试登录。
- 微信：使用微信开放平台网站应用扫码（`qrconnect` + `snsapi_login`）；真实联调待企业/组织主体与网站应用审核。
- 不包含 Yufu 官方微信小程序、`wx.login`、`code2Session`、`/mini/*`、handoff/resume、公众号网页 OAuth。
- 发布归档未做代码签名或公证；Linux 构建基于 Ubuntu 22.04。
- 真实微信/QQ 平台验收完成前，生产环境建议保持对应 Provider 禁用。
